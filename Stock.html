☁️ Firebase Cloud Backup / Sync

🔧 One-time Firebase Setup

Firebase Console → Project settings → Your apps (Web app) se config copy karein. Realtime Database se Database URL copy karein. Admin access Firebase Auth custom claim se verify hota hai; UID yahan enter nahi hoti.

Important: HTML mein Admin UID hardcode nahi hoti. Admin ka haq Firebase Authentication custom claim admin=true aur Database Rules se verify hota hai. Firebase config har device par ek martaba set karein.

Admin ek ya zyada approved emails add kar sakta hai. Har user ko apne approved email se Login/Create Account karna hoga. App ko internet ke sath khula rakhein; Firebase Rules bhi Rules file ke mutabiq publish honi chahiye.

⏳ Live Sync login ke baad connect hogi.

Admin approved email addresses yahan manage karein. Pehle email approve karein; phir doosra user isi email se account banaye ya login kare.
